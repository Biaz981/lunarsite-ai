# LunarSite AI 🌕

**Mission Intelligence Platform for NASA's CLPS Program**

Built by **Biaz Ahmad** | Pakistan | NASA Space Apps Challenge 2026

## 🚀 Live Demo (No Installation Required)
Click here to run the project directly in your browser:
👉 **https://biaz981.github.io/lunarsite-ai/**

## Features
- 🌕 Realistic 3D Moon (NASA LRO textures)
- 📍 12 missions (6 CLPS 2026 + 6 Apollo historical)
- 🧠 AI Site Scoring (0-100)
- 🎮 What-If Simulator
- ⚖️ Mission Comparison
- 📡 Live NASA API
- 🎙️ Voice Narration
- 📅 Timeline Mode (1969-2026)
- ⏱️ Launch Countdown
- 📄 PDF Report Export
- 🎯 Mission Planner (AI)
- 🏔️ 3D Terrain View
- 🛰️ ISS Live Tracker
- 👥 Multiplayer Mode
- 🚨 Rescue Mode (Lost Astronaut Tracker)

## Tech Stack
- Three.js (3D rendering)
- Vanilla JavaScript
- Web Speech API
- jsPDF
- NASA APIs
